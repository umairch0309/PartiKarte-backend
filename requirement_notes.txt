We need a system for creating orders. The frontend sends ticket IDs and their tokens that are connected to Bankart. The order is stored as incomplete until the Bankart API sends a payment verification (3DSecure). When the purchase is confirmed, the ticket ID (for example, 1324523) is generated and stored in the database of events where all the tickets and IDs of those tickets are stored. The user receives a PDF of the ticket with a QR code of the ticket. The orders and tickets will be stored. Each event gets its 5-digit code.



We need an API that receives requests from the scanner app. The scanner app sends the ticket code and the 5-digit event code. The API searches to see if the ticket ID exists in the event and returns success, not found, or scanned at. When there is a success for the scanned ticket, the date and time are entered in the database so one person can enter multiple times with the same ticket.
